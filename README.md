# C语言超市管理系统

本项目是一个基于 C 语言结构体数组和文件读写实现的小型超市管理系统。系统分为用户端和管理员端，支持商品管理、用户购物、VIP 折扣、购物车、库存预警、商品补货、订单记录、销售流水和销售统计等功能，模拟了真实超市从商品入库、前台销售、库存扣减、后台补货到经营统计的完整业务流程。

## 今日新增功能亮点

- 新增管理员登录功能，提高后台安全性
- 程序启动时自动读取商品数据
- 程序退出时自动保存商品和订单数据
- 新增商品补货功能，与库存预警形成业务闭环
- 新增订单记录功能，结算后自动生成销售流水
- 新增订单数据文件 `order.dat`，实现订单持久化保存
- 新增销售流水查看功能
- 新增销售统计报表功能，可统计订单数、营业额、优惠金额和平均消费
- 修复 `salesreport` 函数名不一致导致无法编译的问题

## 本次优化内容

本次优化主要围绕系统稳定性和后台数据可靠性展开。由于项目使用 C 语言结构体数组存储商品、购物车和订单数据，因此增加了商品数量和购物车容量的边界判断，避免数组越界问题。同时，在商品添加和修改过程中加入价格、库存等字段的合法性检查，防止出现负数价格、负数库存等不符合真实业务逻辑的数据。修改商品功能也新增了类别修改，使商品后台管理更加完整。

- 增加商品数量上限保护，避免商品数组越界
- 增加购物车容量保护，避免购物车数组越界
- 添加商品时增加价格和库存合法性检查
- 修改商品时增加价格和库存合法性检查
- 修改商品功能新增类别修改，使后台商品管理更加完整
- 统一 `salesreport` 函数命名，避免编译错误

本次改动虽然不是大型功能模块，但提升了系统的健壮性和实际应用价值。它让超市管理系统不仅能够完成商品管理、购物车、结算、订单流水和销售统计等核心流程，也能在数据录入和数组容量边界方面进行基础保护，使项目更接近真实软件开发中的稳定性要求。

## 项目当前业务闭环

商品入库 -> 商品分类展示 -> 用户浏览商品 -> 加入购物车 -> 普通/VIP 用户结算 -> 自动扣减库存 -> 生成订单流水 -> 管理员查看销售统计 -> 库存预警 -> 管理员补货 -> 数据保存

## 登录账号

- 普通用户：`user / 123456`
- VIP 用户：`vipuser / 888888`
- 管理员：`admin / 123456`

## 数据文件

- `product.dat`：保存商品数据
- `order.dat`：保存订单流水数据

这两个文件由程序运行时自动读取和保存，本仓库只提交源代码和网页展示文件。

## 文件说明

- `超市第二版.c`：C 语言源代码
- `index.html`：项目网页首页
- `style.css`：网页样式
- `script.js`：网页交互逻辑

## 编译运行

```bash
gcc -Wall -Wextra -std=c11 -o supermarket.exe "超市第二版.c"
./supermarket.exe
```
